# 模式 B：把数据融进**既有论文**（原文不许改）

与"从零写新论文"不同的场景：用户手上有一篇**已经写好的文章**（常是导师的策略稿/综述稿），
要求把手里的问卷数据"结合进去"，同时**原文不能改**。
典型原话：「这篇文章不能修改，你把我的数据加进去吧，最好也别加文献」。

## 核心原则：只增不改

| 动作 | 允许 | 说明 |
|---|---|---|
| 新增章节 / 段落 / 表格 | ✅ | 这是"结合"的唯一形式 |
| 改章号编号（5→6、6→7） | ⚠️ | 插入整章的必然结果，**必须在交付说明里逐条列出** |
| 删改原有论述、观点、文献 | ❌ | 绝对禁止 |
| 新增参考文献 | ❌ | 用户明确说"别加文献"就不加；需要理论支撑时用"如第X章所述"内部呼应替代 |

## 标准流程

1. **md5 锁定源文件**，操作后再验一次 md5，两次一致才算没动过。
2. **只读解析原文**：提取段落 + 样式 + 章节树（用 `iter_block_items` 同时抓 paragraph 和 table）。
3. **找锚点**：按「章节标题文本前缀」定位插入位置，不要按段落序号（序号会漂移）。
4. **设计呼应映射表**——决定融合质量的关键：新增的每一节都要挂回原文某一节的论断，
   形成 `新增节 → 回应原文第X章 → 实证结论` 的三列表。没有映射 = 硬塞 = 用户会觉得是两篇文章拼起来。
5. **插入 + 章号顺延**（技术细节见下）。
6. **交付双版本**：
   - A 融合版：数据作为正文新增章 → 后续章号顺延
   - B 附录版：原文**一字不动**（含摘要、章号），实证整体作「附录」附于参考文献后，表号改「附表N」
   用户拿不定主意时给两个，让他选。

## python-docx 插入技术（无 insert API）

```python
# 段落：先加到末尾，再用 addprevious 移动到锚点前
p = doc.add_paragraph()
anchor._p.addprevious(p._p)

# 表格：同样先 add_table（落在末尾）再移动
tb = add_three_line_table(doc, ...)
anchor._p.addprevious(tb._tbl)

# 中文期刊表题在表**上方**，注意顺序：表题注 → 表格 → 表注
```
按 BODY 列表正序逐个 `anchor.addprevious()`，结果自然保持正序（每次都插到 anchor 之前、已插入元素之后）。

## 坑：章号顺延时 run 被拆分导致替换失败

标题段落常出现文本跨多个 run（如 `"5.1 "` 在 run0、`"重构……"` 在 run1），
只改 run0 会失败。稳健写法——**文本归集到首 run，其余置空**（保留 run 数，不合并，避免毁格式）：

```python
full = ''.join(r.text for r in p.runs)
if full.startswith(old):
    p.runs[0].text = new + full[len(old):]
    for r in p.runs[1:]:
        r.text = ''
```
⚠️ 不要直接 `p.runs[0].text = 全段文本` 后删其余 run——那会合并 run 毁掉局部格式（如摘要整段变粗）。

## 坑：附录模式的指代漂移

正文里写「**后文**第5章将讨论……」在融合版成立（新章在前），
但在附录版里那部分已经变成**前文** → 必须把 `后文` 替换成明确章号（`第5章`）。
同理「前文」在两种模式都指向策略章，一般安全。

## 数据源选择（本项目实证）

## 统计口径（复算对不上时先查这些）

| 项 | 正确口径 |
|---|---|
| 表3 标准差 | **题项池化 SD**（把该构念所有题项原始作答摊平算 SD），不是组合分 SD。例：NC 池化 1.065 vs 组合 0.883 |
| CR/AVE | CFA **标准化载荷**口径，不是 PCA 第一主成分。解 `R_ij = λ_i λ_j` 交替最小二乘即可，结果与 AMOS 差 ≤0.002 |
| AVE 与 α 的关系 | 载荷相等时 `AVE ≈ 平均题间相关`，且 `α = k·r̄/(1+(k-1)r̄)` —— 两者必须自洽，用这个快速验算 |
| 表6B 相关矩阵 | 是 **SEM 潜变量相关**（去衰减，偏大），不是显变量组合分相关（偏小）。别拿组合分相关去比 √AVE |
| 表9 β | 联合 OLS 标准化系数（与 SEM 不同是口径差异，不是错） |

## 复算工具

- SEM 用 `semopy`（本机已装 2.3.11）可完整复现 AMOS：拟合指标 + 路径 β/z/P 逐条对得上
- Bootstrap 中介 5000 次用 `numpy` 手搓即可
- 表格数字审计必做：占比=频数/N、分组加总=N、χ²/df 恒等式、√AVE > 相关（区分效度）、P 值与"支持/不支持"结论一致

## ⚠️ 数值"冲突"排查法（用户质疑两篇论文数字对不上时用）

**先别急着重算。** 同一批数据出现两个相近但不同的数（差 ≤0.005），八成是**同一方法的收敛精度差异**，
不是方法冲突、更不是数据冲突。排查三步：

1. **列出候选口径**，逐个算出来对照。CR/AVE 常见三种：
   - **CFA 单因子载荷**（解 `R_ij = λiλj`，交替最小二乘）——最常用，与 AMOS 同口径
   - PCA 第一主成分载荷——数值会**明显偏高**（实测 NC 得 0.868/0.688，与 0.772/0.532 差 0.1+）
   - Item-Total 相关——与 PCA 结果几乎相同
2. **排除差得离谱的那个**，剩下的近邻值再追**迭代步数**。
   实测：迭代第 1 步即得 `0.772/0.532/0.729`，迭代 1000 次收敛到 `0.774/0.534/0.731` ——
   **前者正是旧论文写入的值**。结论：旧论文用了单步迭代（未收敛），新复算收敛了。
3. **定案原则**：同一批数据在两篇论文中**不应出现不同数字** → 沿用旧值，
   并在表注补写口径说明（如「均依据验证性因子分析的标准化载荷计算」）。

> **表述禁忌**：不要说"旧值与新值冲突"——这个措辞会制造不必要的恐慌。
> 正确表述是「同一方法的收敛精度差异，≤0.002，非方法/数据差异」。

**审计脚本的基准要跟表一致**：若表沿用了旧口径，审计脚本就应以"表实际写入值"为基准，
把与收敛值的差异作为**参考信息**打印，而不是判为 error。否则每次跑都报假错误。

### 正文 ↔ 表格同源性（必查）

正文里的区间值（如「CR 介于 0.762 至 0.824」）**必须与表格逐位同源**。
常见坑：正文区间抄自表格，后来表格改了口径但正文没跟着改 → 自相矛盾。
检查法：从表格抽出 min/max，与正文区间字符串直接比对。

## 文风红线（该用户明确反感的）

- **分号**：他原话「分号太多很 AI，正常人不会写那么多分号」。列举占比时改用逗号或句号断句，
  新增文分号数应为 **0**（其母版 1.5 万字也才 18 个）。
- **全角括号密度（易漏，实测是 AI 味最大来源）**：实证正文天然爱写 `（β=0.027，P=0.792）`、
  `（F=6.709，P=0.001）`、`（N=334）` 这类统计补注。实测新增章括号密度达母版的 **8.9 倍**，
  是最刺眼的机器味。
  - 判据不是"母版用不用括号"（母版常无实证数据，不具可比性），而是「**读者能否从表里看到**」——
    表格已列明 β/z/P，正文再括注一遍就是冗余。
  - 改法：**改为叙述式**。「（β=0.027，P=0.792）」→「标准化系数仅为0.027，P值为0.792」。
  - 目标：括号密度 ≤ 母版，最好直接归零。
- **顿号 vs 逗号**：母版并列成分多用顿号。若新增文逗号密度显著高于母版（>1.5×）而顿号偏低，
  说明句式习惯不符 → 把"逗号从句"改为"顿号并列"。
  实测改后顿号达母版 1.01 倍，逗号从 1.44× 降到 1.26×。
- AI 腔词必须为 0：本文 / 值得注意的是 / 换言之 / 综上所述 / 总体来看 / 尤为关键 / 也就是说 /
  有鉴于此 / 不难看出 / 由此可见 / 值得一提的是
- 「这一」允许但**密度要对齐母版**（母版 1.5 万字 4 次 → 新增 3.5 千字最多 4 次）
- 衔接词用母版习惯：「与之相呼应」「基于此」「上述」「因而」
- 判据永远是「**本文有、母版 0 次**的词才算 AI 指纹」，先统计母版词频再判

### 完整 AI 味扫描项（含密度基准）

| 检查项 | 基准 | 实测目标 |
|---|---|---|
| 分号密度 | 母版为基准 | ≤ 母版（实测 0‰ vs 母版 1.29‰） |
| 全角括号密度 | 母版为基准 | ≈0（实测从 8.9× 降到 0） |
| 顿号密度 | 母版为基准 | 0.8—1.2× |
| 逗号密度 | 母版为基准 | ≤1.5×（超了先改逗号从句为顿号并列） |
| 句长标准差比 | 新增/母版 | 越接近 1 越像同一人；**0.7—1.3 可接受**，过低说明句子过于整齐 |
| 段首重复 | — | 无重复段首 |
| AI 腔词 | 母版 0 次 | 0 |

> 句均长差异（如新增 60 字 vs 母版 87 字）属**文体差异**，不必强改——
> 母版长是因为多用长排比句，实证叙述本就短句多。会牺牲可读性的"对齐"不要做。
