# 无缝循环的周期对齐（关键）

GIF 循环播放时，最后一帧 → 第一帧 也是一次「帧间隔」。
所以**循环边界的位移量必须等于普通帧间隔**，否则会看到一次跳动。

## 总原则
把循环长度归一化为 `t ∈ [0, 1)`，`N` 帧取 `t = i/N`（i = 0..N-1）。
**每个随时间变化的量，在一个循环内必须前进整数个「视觉周期」。**

在 `t = i/N` 采样时，该量的瞬时值可直接写成 `t` 的函数——
只要它在 `t=0` 和 `t=1` 处取值相同（或差整数个周期），循环就无缝。

## 各类运动的周期

| 运动 | 视觉周期 | 约束 |
|---|---|---|
| 连续旋转（无对称性，如单臂曲柄） | 360° | 循环内转 **整数圈**：`t * 360 * k` |
| 辐条轮（n 根均布辐条） | 360/n 度 | 循环内转 **任意整数个 360/n**。8 辐条 → 45° 的整数倍即可，不必整圈 |
| 往复摆动（sin） | 2π | `sin(2π * m * t)`，m 必须为整数，否则起止相位不接 |
| 位移/滚动 | 图案自身的重复宽度 P | 总位移 = **P 的整数倍** |
| 粒子（尘土、火花） | 单个粒子寿命 | 寿命 `1/k` 个循环（k 整数），使粒子数在循环内自洽 |

## 滚动地面：把图案铺成能整除的距离
难点：滚动距离由「轮子周长」这类物理量决定，通常除不尽。
**反过来做**——先定总位移，再反推图案重复宽度：

```
TRAVEL = 2 * π * wheel_radius      # 一圈轮的滚动距离
TILE   = TRAVEL / 3                # 把重复宽度定为总位移的 1/3
scroll = -TRAVEL * t               # 循环内正好走 3 个 TILE
off    = scroll % TILE             # 用取模做图案循环
```

`TILE` 非整数完全没问题，坐标用浮点即可。关键是 `TRAVEL / 3` 能整除总位移。

## 联动：让轮子和脚踏互相自洽
踩踏与车轮若都按物理传动比走，传动比往往不是整数（真实自行车约 2.5–4），会破循环。
只需保证**各自**都是整数周期即可，不必强求两者比值等于真实齿比——
观众感知的是「在转」，不是齿比。本项目用：曲柄 1 圈、车轮 2 圈 / 循环。
