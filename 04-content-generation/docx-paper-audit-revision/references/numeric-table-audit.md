# 表格数字审计：先破解口径，再判对错

适用：实证论文定稿前，把"正文数字 × 三线表"整体复算一遍。核心教训：**同一张表的不同列可能来自不同统计口径**，不破解口径就直接判"对/错"必然误判。

## 第一层：机器可复算恒等式（零成本，先全跑）

- 分类频数加总 = N；占比 = 频数/N（多选题 separately）
- 题项数跨表互检（变量定义表 × 描述统计 × 信度表 × 效度表）
- √AVE = sqrt(AVE)；Fornell—Larcker 对角线 > 同列所有相关
- 特征值/k = 方差贡献率；累计逐项加总
- χ²/df = 商；RMSEA = sqrt((χ²−df)/(df·(N−1)))；AGFI = 1−(1−GFI)·[p(p+1)/2]/df
- η² = F·df1/(F·df1+df2)（反推自由度）；t ↔ Cohen d 互推（d=(M1−M2)/pooledSD，t=d·√(n1n2/(n1+n2))）
- **中介表：总效应 = 直接 + Σ间接（数学恒等，任何自洽模型都成立）→ 不等的行必有孤立错误**
- 表题注 ↔ 表对象按文档流映射（有"续"表时物理序号≠题注号）

## 第二层：判出"哪格错"后，用原始数据反推口径

步骤（本项目实例：中介表总效应 2/4 行不齐）：
1. 用原文数据复算标准口径（PROCESS Model 6 偏系数），若与表格对不上 → **别急着判表错**，先怀疑口径不同。
2. 枚举方程池：每个系数的候选来源（简单斜率 / 控 X 偏系数 / 控协变量偏系数），做乘积组合网格，与表格 16 格逐一匹配（容差=末位舍入 0.0016）。
3. 实测破解结果：经由PV = a1(简单)×b1(SI~PV 简单)；链式 = a1(简单)×d21(SA~PV 简单)×b2(SI~PV+SA 偏)；直接 = SI~X+PV+SA 偏 —— 三列各自精确复现 → **这三列没错**。
4. 唯一复现不了的是总效应列的 2 格（差 0.022–0.024，10 倍于舍入）→ **孤立抄写错误**，改为"表内直接+两项间接"（0.482/0.479），NC/IV 行差 0.001 属舍入不动。
5. CI 列：bootstrap(直+间) 与表中 CI 不符、bootstrap(c) 吻合 → CI 列本来来自总效应模型，**点估计修正后仍落在原 CI 内 → CI 不动**（最小改动）。

## 判定纪律

- 差 ≤ 0.0016（末位舍入）→ 一律不算错，**别改**（用户铁律：别一点点错都改）。
- 混合口径导致的"直+间≠c"不是错；**表内印刷值互相矛盾**才是错。
- 修正后必须：表内恒等式全表成立 + 正文引用区间同步改 + 与备份逐格 diff 确认改动面 = 预期。

## 常见"假错"（复算对不上但表没错）

- 描述统计 SD 列 = **题项池化 SD**（不是组合均分的 SD）：均值对上、SD 对不上先查这个。
- 回归表 β 是**标准化系数**（联合 OLS），SEM 表是另一套 —— 两表系数不同不是错。
- 原始数据 Likert 是文字标签（"Agree (4)"）→ 先 `str.extract(r'\((\d)\)')` 转数值；列名匹配别用 split('-')（会被 "open-minded" 坑），用正则 `-(C\d|SC\d|…)\.`。
