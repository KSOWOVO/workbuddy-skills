# 全球宏观·前沿科技·游戏全景智库日报（英文为主 + 弹窗翻译版）

## 触发词
每日简报 / 智库日报 / 深度资讯日报 / 英文研报 / 市场全景分析 / daily briefing / intelligence report

## 交付物
- 主交付：同名 `.html`（`Global_Macro_Tech_Gaming_Intel_2026-09-01.html`），纯内联 CSS/JS 零外部依赖，必须包含：
  1. **选中英文弹中文翻译**：`#dict-pop` 气泡 + `DICT` 词汇对象（金融+雅思词，含词形归一化 normWord）+ mouseup 监听（整句优先、单词兜底、去 s/ed/ing）。
  2. **指数卡片点击弹走势图**：`.idx-card` 点击 → `openModal(key)` → 模态框内 SVG 折线图（`drawChart`，近 40 点，红涨绿跌）+ 近5/20/40日涨跌幅 + PE/分位/点评。
  3. 每条新闻 = `.p-en` 英文段落（主）+ `.cn-box` 折叠中文摘要（`toggleCn`）。
- 辅助：同名 `.md`（英文为主+中文摘要），最后用 present_files 一次呈现（html 放首位）。

## 输出结构（v3 严格模板）
1. 标题行 `# 🌐 Global Macro, Tech & Gaming In-Depth Intelligence | 全球宏观·前沿科技·游戏全景智库`
   + `*Date / Reading Time / Lexical Level*` + 数据口径注 + 顶部操作提示（"选中英文弹翻译 / 点击卡片看走势"）。
2. **Section 1 大盘全景**（按用户知识库指数基金框架，**大盘板块必须全，不许只有美股**）：
   - 1.1 国内宽基矩阵（表格或卡片）：上证指数 / 深证成指 / 沪深300 / 中证500 / 中证1000 / 创业板指 / 科创50 / 红利低波。列：点位、今日涨跌、PE(TTM)、十年分位、估值信号。
   - 1.2 港股与境外宽基（表格或卡片）：恒生 / 恒生科技 / 标普500 / 纳指100，同列。
   - 1.3 中文解读 + EN Summary（各一整段）：按 PE 分位定投法讲清"现在哪些能买/等回落/回避"。
   - 1.4 宏观综述（英文为主段落 + 折叠中文）：货币政策/收益率/油价地缘/A股轮动/港股状态。
   - 1.5 强势板块快讯（每条一行中文 + 一行 EN）。
3. **Section 2-4（AI / 硬件 / 游戏）**：每条目 = `### 编号 中文标题 | English Title` + **英文完整段落**（主，150-200 词）+ **折叠中文全文翻译**（辅，逐句对应 250-400 字，**不是摘要**）+ `*(Source: ...)*`。覆盖过去 24-72h 全部重要动态，末尾可加快讯清单。
4. **Section 5 雅思词汇表**：8-10 个 C1/C2 或 AWL 词汇/搭配（Word | 语境释义 EN+CN | 原文例句），例句必须从本日报正文摘取。
5. 结尾：`*Compiled ... | 行情数据 / 估值分位 / 新闻来源 / 大盘框架*`。

## 语言标准（硬约束）
- **英文为主、中文为辅**：英文段落是主体（IELTS Band 7.5–8.5 正式学术语体：倒装、分词短语、名词化、AWL）；中文是**完整全文翻译**（逐句对应，250-400 字，**不是摘要**），**不要中英整段交替**。
- 全篇无问候、无签名，直接以文档开始。

## 数据源优先级（v3：MCP 优先，WebSearch 兜底）
1. **westock-mcp**：
   - `data_kline` 拉指数日K线（`sh000300/sz399006/sh000001/sh000905/sh000852/sh000688/sz399001/hkHSI/us.INX/us.NDX`，`period:"day"`，`limit:60-130`），返回最新价 + 历史收盘序列（**用于走势图与区间涨跌幅**）。
   - 批量 K 线支持 `codes` 逗号分隔（实测 sh000905,sh000852,sh000688,sz399001 一次成功）。
   - 美股指数代码 `us.INX`（标普500）、`us.NDX`（纳指100）——与之前文档不符时以实际返回为准。
   - 红利低波 `csH30269` 无实时K线 → 卡片降级为纯数据展示（无 sparkline），注明"无实时K线"。
2. **ima-mcp 知识库**：用户知识库《想提前退休·指数基金篇》提供大盘框架（宽基五件套+红利低波+境外宽基+PE 分位定投法）。`search_knowledge` 找文档 → `fetch_media_content` 读全文。
3. **WebSearch（Tier-1）**：宏观/美联储/地缘/公司新闻/估值分位（交易所行情、雪球、方正证券、申万宏源周报给 PE 分位）。
4. 估值分位口径冲突时：优先交易所行情源（如沪深300 72.5% 为交易所口径），脚注注明来源与日期。

## 工作流（务必执行）
1. 并行调用：westock `data_kline`（指数批量，A股8个+港股1+美股2）+ ima `search_knowledge`（指数基金文档）+ WebSearch 4-6 组（美股收盘/A股港股行情/美债美联储ERP/AI大厂/半导体/游戏）。
2. **用 K 线数据算区间涨跌幅**（近5/20/40日 = last/倒数第N根-1），写进模态框；当日涨跌用最新两根 K 线 close 差。
3. 缺估值分位 → WebSearch 补（"沪深300 市盈率 分位数"、雪球估值周报、方正证券金融工程周报）。
4. **交叉核对每个数字**：MCP 实时 > 交易所 > 主流媒体；拿不到精确值 → (est.) + 脚注，**绝不编造**。MCP 数据与早先估算冲突时以 MCP 为准。

## 踩过的坑
- **MCP 行情比估算准**：v1 曾估纳指100 日涨跌 -0.5%，westock 实际 +0.08% —— 指数日涨跌必须用 MCP/交易所数据，别用板块代理值。
- **红利低波指数代码是 `csH30269`**（中证红利低波），PE 8.59、股息率 4.24%；不要用上证红利（不同指数）。且该指数无实时K线 → 卡片降级处理。
- **港股恒生指数 MCP 返回 `pe_ratio:0`**（无 PE），需用 WebSearch 补（雪球周报 ~12x/77% 分位）。
- **`data_kline` 的 `last` 字段 = 最新价/收盘价**，首条即当日；区间涨跌幅 = `last / pts[n-1-k] - 1`，注意指数第 1-2 根量能异常（如 08-31 成交量骤降）是交易所数据特性，不影响价格序列。
- **v5 词典维护策略（任意词必可查，2026-09-01 定型）**：
  - 内置 DICT ≥400 条（公司/产品/人名/术语/正文高频词）秒查；
  - **未命中自动调 MyMemory 在线翻译兜底**：浏览器端 `fetch('https://api.mymemory.translated.net/get?q='+encodeURIComponent(w)+'&langpair=en|zh-CN')`，CORS 头 `Access-Control-Allow-Origin:*` 已实测开放（2026-09-01 验证），8s AbortController 超时；选中文本 >60 字符时只翻前 6 个词；
  - **在线翻译质量验证**（2026-09-01 实测）：encircling→环绕、bifurcated→分叉的、hyperscaler→超大规模、procurement→采购、contagion→疫病——金融/学术词可用；
  - **Google translate gtx 端点在本机网络不通**（被墙/超时）→ 不要用，只用 MyMemory；
  - **三级兜底链**：DICT 命中 → 在线翻译 → 都没中（离线）→ 引导看「▼ 中文全文翻译」；
  - 词形归一化：`normWord` 去 `s/ed/ing/ly/'s` 后缀、先整句（词组）再按单词匹配。
- **index 代码 vs K线**：westock `data_kline` 支持 `codes` 批量（最多实测 4 个一次成功）；美股用 `us.INX/us.NDX` 而非 `us.IXIC`（纳指综指另有代码）。
- 用户知识库检索：关键词用「指数基金 宽基指数 理财」，命中《想提前退休》《存钱=亏钱》等多篇，取讲宽基+定投法的那篇。
- **中英对照是"段落交替"不是"并排双栏"**——v4 改为英文为主+折叠中文全文翻译（按按钮展开），不是摘要段段。
- 其余坑（口径、时点、估值分位口径、宏观人物及时更新、游戏并购找公告）同 v1。
