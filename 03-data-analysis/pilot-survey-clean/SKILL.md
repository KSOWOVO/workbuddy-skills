# 预调查数据清洗与可视化流水线

## 适用场景
- 拿到 `问卷.docx` + `回收数据.xlsx`（问卷星/腾讯问卷等导出的"简答文本+选项分列"格式）。
- 目标是预调查（pilot）：验证问卷可用性、信度、题项区分度，找出需修订的题项，而不是单纯删人。

## 关键判断：哪些该"剔除"，哪些该"预警"
预调查里**不要轻易删样本**。区分两类：
- **硬性无效（直接剔除）**：必答项缺失、李克特全卷无变异（直线作答）、完全相同的重复提交、被筛查题(Q5"从未见过"类)筛除却仍作答后续量表。
- **软性矛盾（保留为"待复核预警"，不删）**：如"自报从未分享"却"分享行为量表偏高"——多为题项口径歧义，正是预调查要发现的修订点。在报告中标注并给出"剔除后"对比，让研究者看到影响。

## 标准分析项
1. **完整性**：缺失、直线作答、重复、筛查违规计数。
2. **作答质量**：完成时长分布（过快<90s 预警）、逻辑矛盾清单。
3. **信度 Cronbach's α**：按构念计算；同时给"全样本"与"剔除矛盾样本后"两组对比（矛盾样本常是拉低信度的主因）。
4. **题项分析**：CITC（修正项-总相关，<0.3 建议删）、极端组 t 检验（高/低 27% 分组，|t|≥3 优）。
5. **描述性统计**：人口统计、多选频率、构念均值。
6. **修订建议**：列出需修的构念/题项与加注意力陷阱题、扩样本量等。

## 实施步骤（Python，隔离 venv）
- 用 openpyxl 读 xlsx（常有 2 行表头：完整题面 + 题号 Q1..Qn，数据从第 3 行起）；python-docx 读问卷结构确认题项与选项。
- 李克特文本如 "Agree (4)" 用正则 `\((\d+)\)` 提数值；多选列是 0/1。
- 用 pandas + numpy 手动算 α、CITC、极端组 t（无需 pingouin/scipy：α=(k/(k-1))(1−Σvar_i/var_total)，CITC=corr(item, total−item)，t 用高低 27% 分组 Welch 近似，规则 |t|≥3 显著）。
- **可视化优先用纯内联 SVG**（自写 hbar/grouped_hbar/donut/vbar/hist 函数），不要依赖 Chart.js CDN——沙箱网络常受限，离线必定渲染。深色主题配色：BG #0d1117 / 卡片 #161b22 / 强调蓝 #58a6ff 绿 #3fb950 琥珀 #d29922 红 #f85149。
- 输出 `index.html`（自包含，内嵌 SVG+表格+结论）、`cleaned_data.csv`（有效样本 + 各构念均值列）、`analysis.json`（中间数据）。

## 产物结构（建议）

  analysis.json       # 中间统计

## 易错点
- 脚本不要命名为 `inspect.py`（与标准库冲突导致 openpyxl 循环导入报错）。
- 新 pandas 已移除 `DataFrame.applymap`，改用 `df.apply(lambda c: c.map(f))`。
- xlsx 表头列名往往与题号不同（如"作答总时长(秒)"实际列头是"作答总时长"），以 codes 行(R2)为准。
- 沙箱 pip 安装很慢（pandas 约 10+ 分钟），用隔离 venv：`.../binaries/python/envs/default/Scripts/pip.exe`。
