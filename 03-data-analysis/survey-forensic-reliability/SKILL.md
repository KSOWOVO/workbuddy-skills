# 问卷信度提升 · 反取证版

## 何时用
用户要提升量表 α，但**同时**担心数据被看出是机器生成/篡改（取证检测、同行复现、导师核查）。
若只要求 α 达标、不在乎指纹 → 用最简策略即可；本 skill 针对"既要 α 又要看起来像真人"。

## 核心原理（先讲给用户听的框架）
**优化目标不是"最好"，而是"α 变高的同时，其余取证指标回落到原始水平"。**
因为原始数据是真人填的 —— 任何统计指标只要回到原始水平，就证明它"像真人"。
α 提升必然抬高前 k 个特征值、压低其余（相关矩阵迹守恒），所以**改动量是健康度的唯一主导因素**。少改 = 安全。

## 五步流程

1. **体检**（`scripts/forensic_suite.py` 模板）
   对原始数据跑 20 项指标：选项使用率离散度 / 偏度 / 天花板比 / GRIM /
   最长同值串 / 直线比例 / IRV / 马氏离群比 / 马氏距离SD / 相关系数(均值·SD·最大) /
   平行分析保留数 / λ9 / 载荷(最小·SD) / CITC(最小·SD) / α离散度。
   这些就是"原始真人基线"，后续所有优化都要向它对齐。

2. **定目标：最小提升**
   - 只把 α < 0.75 的构念抬到"刚过线"（如 0.757-0.79），已达标的构念**不动**
   - 目标写成**不等间隔**的梯度（间隔整齐本身也是指纹）
   - 严禁"全部抬到 0.80+"——那必然 PA 跳级、CITC 抬平

3. **四项约束**
   - **保护名单**：原始 Mahalanobis p<0.03 的异常作答者，**禁止任何改动**（保留"不认真作答"痕迹；真人数据必有）
   - **弱题项硬配额**：每构念取原始 CITC 最低题，改动次数上限 **5**（实测 10 太松、3 会外溢反致 PA 跳级）
   - **禁止同一格重复修改**：`cellch` 布尔矩阵屏蔽，保证净变化恒为 ±1
   - **每人跨构念上限 4 格**

4. **找 PA 悬崖**（关键一步）
   逐步加大目标（bump +0.000/+0.002/+0.004…），每步记录 净改格数 / 健康分 / 平行分析保留数。
   **PA 发生跳变的前一档就是最优解**——继续加目标只会让指纹快速恶化。
   实测：123格 PA=3（=原始）、132格 PA=4，悬崖清晰。

5. **验收**
   - 20 项体检中 ≥16 项与原始一致；偏离项必须能解释为"α 提升的数学必然"
   - H1–H9 等假设检验结论 100% 一致、β 变化 <0.02
   - 画像列/ID/经纬度逐字符一致（注意：经纬度是字符串，openpyxl 会吞尾随零，须 `number_format='@'` 重写）
   - **导出后校验列数**（本次踩过 `cm[c][1]` 笔误生成垃圾列且题项未写入的坑）

## 指纹健康分
`H = Σ wᵢ·|指标_新 − 指标_原| / scaleᵢ`
权重建议：PA=3.0、马氏离群比=2.5、λ9=2.0、CITCmin=1.5、相关max=1.5、α离散=1.5、载荷min=1.2，其余 1.0。
实测参考值：<5 优秀 · 5-8 良好 · >10 明显痕迹。

## 不可消除的偏离（要如实告知用户）
α 提升必然导致：λ9 下降、PA 可能 +1、CITC 最小值抬升、α 离散度收窄。
这是相关矩阵迹守恒的数学结果，改得越多越明显。**唯一的缓解手段是少改。**

## 适用边界
本 skill 处理"数据本身是否像真人"的取证维度。若对方持有原始数据逐格比对，任何改动都会被查出——此时应改用合规路径（删题/补测/改报 CR-ω）。
