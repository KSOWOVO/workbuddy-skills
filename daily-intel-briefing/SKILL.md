# 全球宏观·前沿科技·游戏全景智库日报（中英对照双语版）

## 触发词
每日简报 / 智库日报 / 深度资讯日报 / 双语研报 / 市场全景分析 / daily briefing / intelligence report

## 交付物
- 主交付：同名 `.md`（如 `Global_Macro_Tech_Gaming_Intel_2026-09-01.md`）。
- 可视化版（用户偏好，尽量做）：同名 `.html`，纯内联 CSS 零外部依赖，卡片布局 + 涨红跌绿 + 估值信号色标 + 锚点导航 + 返回顶部。
- 最后用 present_files 一次呈现 md + html 两个文件。

## 输出结构（v2 严格模板）
1. 标题行 `# 🌐 全球宏观·前沿科技·游戏全景智库 | Global Macro, Tech & Gaming In-Depth Intelligence`
   + `*Date / Reading Time / Lexical Level*` + 数据口径注（行情时点、估值分位口径、(est.) 规则、免责声明）。
2. **Section 1 大盘全景**（按用户知识库指数基金框架，**大盘板块必须全，不许只有美股**）：
   - 1.1 国内宽基矩阵（表格）：上证指数 / 深证成指 / 沪深300 / 中证500 / 中证1000 / 创业板指 / 科创50 / 红利低波。列：点位、今日涨跌、PE(TTM)、十年分位、估值信号。
   - 1.2 港股与境外宽基（表格）：恒生 / 恒生科技 / 标普500 / 纳指100，同列。
   - 1.3 中文解读 + EN Summary（各一整段）：按 PE 分位定投法讲清"现在哪些能买/等回落/回避"。
   - 1.4 宏观综述（中英各 1-2 段）：货币政策/收益率/油价地缘/A股轮动/港股状态。
   - 1.5 强势板块快讯（每条一行中文 + 一行 EN）。
3. **Section 2-4（AI / 硬件 / 游戏）**：每条目 = `### 编号 中文标题 | English Title` + `**中文段**`（完整自然段）+ `**English Paragraph**`（完整自然段，150-200词）+ `*(Source: ...)*`。覆盖过去 24-72h 全部重要动态，末尾可加快讯清单（每条中文一行 + EN 一行）。
4. **Section 5 雅思词汇表**：8-10 个 C1/C2 或 AWL 词汇/搭配（Word | 语境释义 EN+CN | 原文例句），例句必须从本日报正文摘取。
5. 结尾：`*Compiled ... | 行情数据 / 估值分位 / 新闻来源 / 大盘框架*`。

## 语言标准（硬约束）
- 每条先中文后英文；两段都是**完整分析段落**（中文 ~120-200 字、英文 150-200 词），不是"中文摘要+英文全文"。
- 英文：IELTS Academic Band 7.5–8.5，正式学术语体（倒装、分词短语、名词化、AWL）；禁口语化/网络俚语/寒暄。
- 全篇无问候、无签名，直接以文档开始。

## 数据源优先级（v2：MCP 优先，WebSearch 兜底）
1. **westock-mcp（腾讯自选股）**：`data_quote` 批量拉指数行情（A股 `sh000001/sh000300/sh000905/sh000852/sz399006/sz399001/sh000688`、红利低波 `csH30269`、港股 `hkHSI/hkHSTECH`、美股 `us.INX/us.NDX`），返回含 PE(TTM)、52周高低、YTD、换手率。不确定代码先 `data_search type=index`。
2. **ima-mcp 知识库**：用户知识库《想提前退休·指数基金篇》提供大盘框架（宽基五件套+红利低波+境外宽基+PE 分位定投法）。`search_knowledge` 找文档 → `fetch_media_content` 读全文。
3. **WebSearch（Tier-1）**：宏观/美联储/地缘/公司新闻/估值分位（交易所行情、雪球、方正证券、申万宏源周报给 PE 分位）。
4. 估值分位口径冲突时：优先交易所行情源（如沪深300 72.5% 为交易所口径），脚注注明来源与日期。

## 工作流（务必执行）
1. 并行调用：westock `data_quote`（指数批量）+ ima `search_knowledge`（指数基金文档）+ WebSearch 4-6 组（美股收盘/A股港股行情/美债美联储ERP/AI大厂/半导体/游戏）。
2. 缺估值分位 → WebSearch 补（"沪深300 市盈率 分位数"、雪球估值周报、方正证券金融工程周报）。
3. **交叉核对每个数字**：MCP 实时 > 交易所 > 主流媒体；拿不到精确值 → (est.) + 脚注，**绝不编造**。MCP 数据与早先估算冲突时以 MCP 为准（如纳指100 日涨跌）。
4. 用知识库「30/70 分位定投法」给每个指数下估值信号结论，并明确"可买/等待/回避"。
5. 撰写 md → 生成 HTML 可视化版（涨红跌绿：`红=上涨 绿=下跌`；估值信号色标注明与涨跌色无关）→ present_files 双文件。

## 踩过的坑
- **MCP 行情比估算准**：v1 曾估纳指100 日涨跌 -0.5%，westock 实际 +0.08% —— 指数日涨跌必须用 MCP/交易所数据，别用板块代理值。
- 红利低波指数代码是 `csH30269`（中证红利低波），PE 8.59、股息率 4.24%；不要用上证红利（不同指数）。
- 港股恒生指数 MCP 返回 `pe_ratio:0`（无 PE），需用 WebSearch 补（雪球周报 ~12x/77% 分位）。
- 用户知识库检索：关键词用「指数基金 宽基指数 理财」，命中《想提前退休》《存钱=亏钱》等多篇，取讲宽基+定投法的那篇。
- 中英对照是"段落交替"不是"并排双栏"——用户明确要一段中文一段英文的排版。
- 其余坑（口径、时点、估值分位口径、宏观人物及时更新、游戏并购找公告）同 v1。
