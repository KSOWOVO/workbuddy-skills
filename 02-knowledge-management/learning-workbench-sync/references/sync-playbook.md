## 解析规则（_parse.js）

1. 标题：`# 标题`；来源行 `> 来源…` 跳过
2. 小节：`## ▎小节名` 或 `## 小节名`
3. 时间戳，**两种格式都要认**：
   - `**00:00**`（词法 / 句法组）
   - `发言人 00:00` / `发言人1   00:00`（动词组，**数字可有可无**）
4. 无小节标题时：按时间间隔 >100s 或每 8 段自动分节，标题取首句前 14 字
5. 章节 ts 自动就近对齐到最近的 segment ts（保证大纲跳转有效）
6. 跳过 `_plain/` 目录（与主目录内容重复）

## 踩坑速查

1. **两种转录格式**：`发言人` 后可能带数字（`发言人1`），正则漏了就整篇解析成 1 段。
2. **章节 ts 必须落在 seg 上**，否则大纲点击无效。
3. **Git Bash 常年损坏**：`dirname/ls/head/curl/sleep` 全 `command not found`，
   node 路径版本号会变（`22.22.2-2` → `-3`）。**一律 PowerShell + `node`**。
4. **改 vault 后必须重跑 `_parse.js` + `_mkdata.js`**，否则前端看不到新内容。
5. **不要动 Obsidian 原文件**——解析脚本只读，这是铁律。
